# 🛠️ Технологический стек для разработки проекта

**Цель:** Быстрая и простая разработка системы складского учета (WMS) с минимальным порогом входа.

## 📦 Компоненты стека

| Слой | Технология | Зачем нужна (Обоснование) |
| :--- | :--- | :--- |
| **Frontend** | React (Vite) + Tailwind CSS | Быстрый UI, адаптивность под мобильные ТСД и ПК. Vite ускоряет сборку. |
| **Backend** | Python + FastAPI | Минимум кода для API, автоматическая документация (Swagger), высокая скорость. |
| **База данных** | PostgreSQL | Надежное хранение остатков, истории операций и справочников. |
| **ORM** | SQLAlchemy | Удобная работа с БД на Python без написания сложных SQL-запросов. |
| **Контейнеризация** | Docker + Docker Compose | Одинаковое окружение на любом ПК. Легко развернуть одной командой. |
| **Деплой** | GitHub Actions + Render | Автоматическая сборка и публикация при пуше в репозиторий. |
